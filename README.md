## 🌐 Free Deployment to GitHub Pages

1. In your GitHub account ([LilyyAnalyst6](https://github.com/LilyyAnalyst6)), create a new repository named `portfolio` or `lilyyanalyst6.github.io`.
2. Push your portfolio files:
   ```bash
   git init
   git add .
   git commit -m "Curate entry-level data analytics portfolio with carousel and case studies"
   git branch -M main
   git remote add origin https://github.com/LilyyAnalyst6/<your-repo-name>.git
   git push -u origin main
   ```
3. Navigate to **Settings** > **Pages** in your repository.
4. Set source branch to `main` and root `/`, then save.
5. Your live portfolio will be active at `https://LilyyAnalyst6.github.io/<your-repo-name>/`.
