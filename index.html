Passion & Purpose

My Journey & Approach

Every dataset has a story. I like finding it. I got into data analytics because I wanted to know why trends change, where things get stuck and how evidence can help people decide better. Messy data does not scare me. Cleaning it is where I learn the most. The three steps are: clean the data, ask clear questions, show it simply. My workflow follows a three-pillar approach:

  • 01
    Curate with Integrity: Clean, filter, and validate raw datasets using Excel, SQL, and foundational Python (Pandas) so every baseline number is reliable.
  • 02
    Model with Purpose: Frame testable questions, engineer informative DAX & SQL metrics, and cross-check calculations against source data.
  • 03
    Design for Humans: Eliminate visual noise and build intuitive Power BI & Tableau dashboards that communicate findings effortlessly to any team member.

Alongside core business intelligence tools, I am actively expanding my capabilities with foundational Python for programmatic data wrangling and exploratory data analysis. As an entry-level analyst, I bring high energy, a strong work ethic, genuine humility, and an eagerness to absorb mentorship and contribute meaningfully to a data-focused team.

Meticulous Data Cleaning: Treating data preparation with obsessive care—resolving nulls, duplicates, and type mismatches before calculating metrics.
Foundational Python: Applying Python (Pandas & NumPy) for script-based exploratory data analysis and basic data manipulation.
Visual Clarity & Storytelling: Crafting dashboards that bridge analytical logic with simple, practical visual communication.
